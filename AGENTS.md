# AGENTS.md

Coding agents working in this repository must start with Project Atlas.

1. Read `Project Atlas/skills/agent-bootstrap.md` and follow it.
2. Inspect actual code before changing anything.
3. Work on branches, open pull requests, never merge — the owner merges.
4. Never touch secrets, the ledger, pricing, auth, permissions, or
   production behavior without explicit owner approval.

Atlas is the canonical documentation hub. `docs/HANDOFF.md` is preserved
as-is. When documents contradict, code and verified evidence win.
