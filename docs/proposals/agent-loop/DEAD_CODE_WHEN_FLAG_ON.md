## Read this first: what the hook does NOT take

The hook skips a turn that is a test scenario, a **guest** turn, a file-shaping turn, a greeting or a general question. Those turns still run the post-hook region. In particular a **guest's research request is still planned by the old hand-coded path** (guests are kept off the planner on purpose: a sample call spends provider money). So nothing below can be deleted until one of these is decided: guests get a planner without sample calls (catalog search and describe only), or guest plans are removed. The lists are the code that has **no other caller** than the post-hook region of the chat handler; for a signed-in customer's research turn it is never reached.
