# خطة تسليم ما طلبه العميل بدقة (DT-20261118-03)

## الهدف
تصحيح ثلاثة طلبات واقعية للعملاء أظهرت الجودة فيها فجوات (طلب شركات كهروميكانيكا ومديرين وإيميل وتليفون، طلب شركات مقاولات في القاهرة بالإيميل والتليفون، طلب يوتيوب مع زر أي نتيجة).

## الطلبات المقسمة
- أولًا (PR-1): تثبيت عدد ٢ مديرين لكل شركة (قرار D-0083 O-1).
- ثانيًا (PR-2a / PR-2b): قراءة أرقام التليفونات لجميع الأشكال ومنع وضع رقم الشركة للشخص (D-0084).
- ثالثًا (PR-3): منع بريد الشركة العام في خانة الشخص، مع الاحتفاظ بالعناوين القيادية (ceo@، gm@، manager@، director@).
- رابعًا (PR-4): خطوة إيميل الشركة لطلبات الشركات بدون أشخاص، وتخطيها لو العمود موجود.
- خامسًا (PR-5): استبعاد المدن الأخرى عند طلب مدينة معينة (مثل استبعاد الجيزة عند طلب القاهرة).
- سادسًا (PR-6): زر الخروج المباشر «أي نتيجة عن الموضوع تكفي، اختاروها أنتم» في أسئلة البحث.
