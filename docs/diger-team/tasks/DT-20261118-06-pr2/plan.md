# فاحص مهمة الإدارة (قراءة فقط) + متابعات PR 1 (DT-20261118-06، PR 2)

رابط الطلب: سيُضاف بعد فتح الـ PR

قرار ميجز D-0104: صفحة للإدارة (حساب القراءة فقط للفريق) تعرض مهمة واحدة: نداءات الكتالوج وحالتها ورمز HTTP وسبب الفشل وعدد الصفوف، الأخطاء، حالة كل مرحلة، وقرار المخطط. بلا أسرار ولا بيانات دفع ولا خانات تواصل العملاء.

## ما اتبنى
- **`GET /api/admin/missions/[id]/inspect`** (`src/app/api/admin/missions/[id]/inspect/route.ts`): أدمن فقط، `GET` فقط (الملف مبيصدّرش غيره: مفيش مسار بيقبل body)، `force-dynamic`، المعرّف `msn_…`، صف إضافة (add-on) = 404.
- **`src/lib/server/adminMissionInspector.ts`**: قراءة بأعمدة مسمّاة (مفيش `select("*")`)، والرد كله بقائمة سماح: مفيش `sample_rows` ولا قيم `params_digest` (أسماء المفاتيح بس) ولا `user_id` ولا إيميل/تليفون العميل ولا مسارات تخزين ولا دفتر ولا إعدادات خاصة ولا `worker_id`. كل نص بيعدّي على `redactText` (إيميل، تليفون ≥ ٧ أرقام، Bearer/sk-/eyJ، hex/base64 طويلة، query الروابط)، ونصوص الفشل والخطأ على `redactFailure` الأشد (بتشيل مش بتخبّي: نصوص بين علامات اقتباس، روابط، قيم headers، أرقام ≥ ٤، رموز مختلطة، أسماء مسارات و slugs، كلمات لاتينية بحرف كبير داخل الجملة، وأي كلمة بحروف عربية). وبعدها **مشي أخير** بيرمي (500) لو نص لسه شكله سر.
- **الصفحة** `/admin/missions/[id]` + `MissionInspector.tsx`: المهمة، قرار المخطط (مع سبب عدم وجود كارت بالعربي)، المراحل (حالة كل مرحلة، «سعر تقديري»، «مصدر مشترك»)، الاستدعاءات (الفاشلة والمرفوضة أولًا، تصفية، إجمالي لكل مصدر)، الأحداث (الداخلية باهتة). RTL بفئات منطقية فقط، مفيش form ولا input، والأزرار الوحيدة شرايح التصفية. رابط «فحص المهمة» من `/admin/agent`، ولون لإجراء `inspect` في سجل المراجعة.
- **متابعة**: القراءة المرقّمة للنظرة العامة بترتّب بـ `created_at` ثم `id`. **Tier A (أنا كتبته)**: اختبار الأمان D-0098 (`safety-migration-one-open-addon`) بحدّ كلمة من اليسار `(?<![a-z0-9])missions` بدل `/missions/i`: «admissions/permissions/submissions» تعدّي، وكل حالة D-0098 تسمّيها لسه بتفشل (فزاع أكّد النية في Gate 1 P1-3).

## Gate 1 (فزاع): ملاحظات اتطبّقت
P1-1 المراجعة (audit) مرة واحدة عند فتح الصفحة (`?first=1`) مش مع كل استطلاع، ولا مع 400/403/404. P1-2 تنقية نصوص الفشل (فوق) مع حالات جدول للمفاتيح القصيرة وأسماء المسارات؛ المتبقي صراحةً: اسم صغير الحروف مكتوب كأي كلمة عادية ما بيتعرفش، والنص مقطوع عند ٢٠٠ حرف ومقروء للفريق بس. P1-3 كما فوق. P2-1 لون/تسمية الإجراء. P2-2 نداء بيخدم مرحلتين (مصدر مشترك) بيتعدّ في كل مرحلة وبتعلّم `sharedEndpoint`. P2-3 `truncated` مع الإجمالي الحقيقي (عدّ). P2-4 مجموعة حروف مفاتيح `params_digest` مختبرة.
