## 2. Core Architectural Invariants Enforced

1. **Strict Count Separation Guarantee (Point 4.1):**
   - Rows retrieved from related accounts are tagged with `scope: "widened_account"`.
   - Primary account rows are tagged with `scope: "primary_account"`.
   - Primary count ($N$, e.g. 5) is strictly reported as $N$, never inflated by widened rows ($N+M$). Widened count ($M$, e.g. 11) is reported separately in scope breakdowns.
   - `uiPayload.true_n` strictly reflects primary count.

2. **Live Sheet & Workbook Parity (Point 4.2):**
   - `deliveryRowsOf` populates `scope_label_ar` as an explicit cell column (`نطاق المصدر`) in both the live sheet snapshot and the delivered workbook.
   - Parity guarantee: `liveSnapshot.rows.length === deliveredWorkbook.rows.length`.
   - Done live snapshot embeds `stop_reason_ar` and `coverage_note_ar`.

3. **Dynamic Wording from Approved Proposals (COMMANDER Design Check):**
   - Zero hardcoded topic, source category, or provider words in code.
   - The Arabic label of each widened scope and summary text derive strictly from the widening proposal produced by the LLM and approved by the customer (`titleAr`).
   - The code only fills numbers: e.g. `«وجدنا {n} من الحساب المطلوب، بالإضافة إلى {m} من {proposal.title_ar}»`.
   - Neutral fallback when no proposal title is given: `«من نطاق أوسع وافقت عليه»`.
   - Must-pass test cases verify dynamic labels for rumors cases, non-rumors cases (company + partner network), and the neutral fallback.

4. **Zero Discrepancy Invariant (Arrival & Dedup Guarantee):**
   - An accepted row appears in the live sheet only after deduplication and acceptance.
   - Unjudged / pending rows (`state: "pending"`) and excluded rows never appear in `liveSnapshot.rows`.
   - An accepted row never disappears across sequential snapshots.

5. **Customer Text Guard Compliance:**
   - All customer-facing option texts pass `checkCustomerText` with 0 issues:
     - Option 1 (Deliver primary): `"سلّمني الموجود فقط (عدد {N}) من الحساب المطلوب"`
     - Option 2 (Widen): `"وسّع البحث ليشمل {titleAr}"` (neutral: `"وسّع البحث ليشمل نطاق أوسع وافقت عليه"`)
     - Option 3 (Official Full Archive Search): `"البحث في الأرشيف التاريخي الشامل للمنصة (بتكلفة إضافية)"`
   - Zero English words, zero ASCII digits (Arabic-Indic digits only).
