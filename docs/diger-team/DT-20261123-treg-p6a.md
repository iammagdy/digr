## 1. Overview & Architectural Motivation

On main, Diger operates with three live data providers:
1. **TREG:** 3,276 sellable endpoints across 106 platform families.
2. **Firecrawl:** Web search, site mapping (`site.map`), page scraping (`page.read`), and structured JSON scraping (`page.read_structured`).
3. **Context.dev:** Web search, site mapping (`site.map`), page scraping (`page.read`), structured JSON scraping (`page.read_structured`), and people search (`people.search`).

Prior to Phase 6, Firecrawl and Context.dev were confined to single «web search» endpoints in the planner (`directWebEndpoints`), preventing the model from discovering their full capabilities (such as mapping official entity domains and bounded scraping). 

Phase 6 Part 1 unifies all three providers into a consistent, data-driven contract catalog (`EndpointAdapterContract` shape) with declarative capability tags, strict zero-guessing invariants, and circuit breaker rate-limiting and credit-exhaustion failover rules.

  6. `contextdev.map` (`site.map`) — $0.00254 USD (1 credit @ $0.00254)

  9. `contextdev.people_search` (`people.search`) — $0.0254 USD (10 credits @ $0.00254)
- **Zero-Guessing Invariant:** Any parameter or limit not declared remains strictly `null`, never defaulted.
- All synthesized contracts carry `contract_status: "full"`, validated inputs/outputs schemas, and deterministic SHA-256 schema fingerprints.

### Point 6.2 (Amendment 1 - Megz D-0086 / D-0198): Declarative Capability Tags
- Capability tags are declared in contract data (`discover.web_search`, `site.map`, `page.read`, `page.read_structured`, `people.search`).
- Planner candidate selection uses declarative tag filtering (`filterContractsByCapabilityTag`).
- Zero hardcoded step-type-to-provider mappings in selection or routing code.
- Planner LLM output schema remains invariant.

### Point 6.4 (Amendment 2 - Megz / الكبير): Circuit Breaker & 429 Retry Rule
- **HTTP 429 Rate Limiting:** Strictly preserves Phase 2 behavior: exactly 1 counted retry honoring `Retry-After`; HTTP 429 is not a circuit failure and does not trip the circuit breaker.
- **HTTP 402 / Credit Exhaustion:** Only HTTP 402 trips the circuit breaker to `open` for that provider account.
  - Tripping to `open` immediately routes subsequent calls to alternative candidate providers without retrying or wasting budget.
  - Emits an operational alert log for الكبير (`[CIRCUIT_BREAKER_ALERT: COMMANDER]`) for Megz credit top-up.
  - Can be manually reset via `resetProvider(provider)`.
- **Zero Provider Names in Logic:** Dynamic provider prefix extraction (`endpointId.split(".")[0]`) ensures 0 hardcoded provider brand names in `circuitBreaker.ts`.
